# CLI onboarding preview

These previews render output captured from the local 0.2.3 executable in a real pseudo-terminal, at 88 and 40 columns. They use a dark terminal palette; the user's shell controls its own background, font and ANSI colours.

- `cli-onboarding-wide.png`: wide terminal with horizontal build choices.
- `cli-onboarding-narrow.png`: compact block letters and stacked build choices.
- Matching `.txt` files contain the captured text with terminal control sequences removed.

The captures stop at type selection, using an isolated local test token. They do not authenticate a real account, contact the production API or submit a listing.
